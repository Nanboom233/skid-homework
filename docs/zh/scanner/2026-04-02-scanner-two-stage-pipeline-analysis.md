# 2026-04-02 扫描器两阶段链路再分析

## 目标重述

最终要处理的不是“标准证件平拍”这种单一任务，而是：

- 大致平放的文档
- 大致平放的书本页面
- 页面整体多数是平的
- 但局部可能斜侧，尤其靠书脊的文字会出现轻度弯曲

这类输入的核心诉求不是单纯“找出页面”，而是：

1. **先裁切出正确区域**
2. **再把文字整理成更适合 OCR / CV 的形态**

所以方案必须从“单个检测器问题”升级为“**两阶段几何处理问题**”。

## 结论：必须拆成两阶段

## 阶段一：定位与粗裁切

阶段一的目标是：

- 从背景中找到文档/书页
- 提供粗 ROI
- 提供粗角点或粗 mask
- 保证高召回，不漏页

这个阶段不需要直接达到最终 OCR-ready 精度。

### 阶段一推荐

**YOLO Pose（4 keypoints）**

原因：

- 能直接输出 4 个粗角点
- 对大致平放页面足够自然
- 训练成本低
- 与桌面 Rust + ONNX Runtime 部署对齐

## 阶段二：几何矫正与文字展平

阶段二的目标是：

- 把阶段一裁出的 ROI 做几何精修
- 输出给 OCR / CV 可复用的标准化图像

它才是“真正决定识别质量”的阶段。

### 阶段二需要处理两类情况

#### A. 普通平面文档

如果页面只是：

- 倾斜
- 轻度透视
- 光照不均

那么阶段二只需要：

1. 精细角点修正
2. perspective transform
3. 增强 / 去噪 / 旋转归一

这部分可以在现有 `scanner_postprocess.rs` 基础上继续做。

#### B. 书脊附近轻度弯曲文字

如果页面主体平整，但靠内侧文字弯曲，那么仅靠四点透视变换通常不够。

原因：

- 四点透视只能处理**平面单应变换**
- 书脊侧文字弯曲属于**局部非线性形变**

所以阶段二必须再加一层：

1. text-line / edge-based curvature estimation
2. 局部网格或位移场展平
3. 再做增强和 OCR 输出

## 为什么不让 YOLO 直接一步做完

因为这会把两个性质不同的问题绑死在一起：

### 问题 1：在哪儿

- 页面在哪
- 书页在哪
- 粗角点在哪

### 问题 2：怎么变平

- 透视怎么修
- 文字曲线怎么拉直
- OCR 需要怎样的输出

把这两件事交给一个检测模型，会带来三个问题：

1. 训练目标冲突
2. 调试困难
3. OCR 复用性差

所以更合理的 owner 划分是：

- **YOLO 负责“找对地方”**
- **CV / geometry 负责“整理成可识别图像”**

## 对当前项目的直接含义

### 新的职责划分

#### `scanner_detect.rs`

负责：

- 阶段一
- YOLO 定位 / 粗裁切
- provider 选择
- 粗角点输出

#### `scanner_postprocess.rs`

负责：

- 阶段二
- perspective transform
- enhancement
- 后续可扩展轻度 dewarp / flatten

### 这也解释了为什么 YOLO Pose 更适合

既然 YOLO 只负责阶段一，那么它不需要承担“最终文字展平”的责任。

这时选择标准就变成：

- 谁最便宜
- 谁最稳
- 谁最容易把 ROI 找出来

在这个标准下：

1. **YOLO Pose（4 keypoints）** 最合适
2. **Segmentation** 次之
3. **OBB** 仍然不推荐作为主路线

## 最终建议

### 产品级链路

```text
Stage 1
Native YOLO Pose
-> page / book ROI
-> coarse 4 corners

Stage 2
CV / Geometry Postprocess
-> refine corners
-> perspective warp
-> optional local dewarp near spine
-> enhancement
-> OCR / CV reusable image
```

### 现在最应该做什么

不是直接训一个“万能检测模型”，而是先把工程链路定死：

1. Rust 原生阶段一骨架
2. 阶段二后处理 ownership
3. 阶段二扩展点（平面 / 轻度弯曲）
4. 再推进模型训练

## 与前一轮结论的关系

前一轮结论“YOLO Pose 优于 OBB”仍然成立。  
这一轮补充的是：

> **YOLO Pose 也不应该负责最终 OCR-ready 展平，它只该负责第一阶段。**

这一步收敛后，整体方案比之前更稳，也更符合你描述的真实扫描目标。
